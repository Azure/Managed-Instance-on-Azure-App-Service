# Contributing

1. Create a focused branch from the default branch.
2. Keep credentials and environment-specific deployment values out of commits.
3. Restore dependencies and build `devShop.sln` before submitting changes.
4. Describe behavior and security implications in the pull request.
5. Confirm that you have the right to contribute all code and assets in the change under the MIT license.

Security vulnerabilities must be reported using the process in `SECURITY.md`, not through public issues.
