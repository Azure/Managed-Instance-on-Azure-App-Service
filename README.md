# Managed Instance on Azure App Service

This repository supports Managed Instance on Azure App Service, which is generally available for Windows web apps in select regions on Pv4 and Pmv4 pricing plans. Managed Instance doesn't support Linux or containers.

This repository contains additional 

- [frequently asked questions](FAQ.md)
- [Example configuration/installation scripts](Example-Installation-Scripts/directory.md) based on common customer scenarios.

> [!NOTE]
> Any script provided in this repository should be used as an example only.  You are free to use the scripts but must modify and validate for your own scenario and use.

The documentation for Managed Instance on Azure App Service can be found on [learn.microsoft.com](https://aka.ms/managedinstanceonappservicedocs) within the Azure App Service product documentation.
